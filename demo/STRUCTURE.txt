Key Features
============

demo1 (GDELT News Aggregator):
- Framework-agnostic news aggregation
- 6 categories: politics, tech, finance, gov, ai, intel
- Alert detection, region detection, topic tagging
- Event-driven architecture
- Zero runtime dependencies

demo2 (Federal Reserve Monitor):
- Framework-agnostic Fed data monitoring
- Economic indicators: Fed Funds, CPI, 10Y Treasury
- Fed news from 5 RSS feeds
- Event-driven architecture
- FRED API integration (free)

Both modules:
- TypeScript with full type definitions
- Can be used with React, Vue, Angular, or vanilla JS
- Include working examples
- Comprehensive documentation
- Ready for production use
